# deploy-observatory

## Problema

Uma empresa possui aplicações distribuídas entre **AWS** e **GCP**.

Quando um deploy falha, a equipe precisa procurar manualmente em diferentes pipelines, logs e servidores para entender o que aconteceu.

O objetivo deste projeto é explorar uma solução para **centralizar e facilitar a investigação de falhas em deployments**, independentemente da cloud.
